# Временные файлы Sevenzip

Актуализация макета v64. Отдельный менеджер исключён. Очистка автоматическая с защитой используемых и изменённых копий.
Описания прежних поверхностей ниже сохранены для справки. См. [план интерфейса](implementation-scope.md).

Статус: автономная проработка 5 ноября 2026. Это список копий приложения,
а не второй файловый менеджер для произвольной системной временной папки.
В макете убраны адрес, переход вверх и технические имена каталогов как основная
навигация. Показаны понятное имя файла, состояние и действия; полное место доступно
в подсказке и сведениях сеанса.

Уточнение 7 ноября, source-v59: список переработан в отдельные строки с
разделителями и явными группами. Имя и состояние слева, действия справа;
в компактном окне действия переходят под сведения с сохранением отступов.
Дублирующий путь не показан: полный путь временной копии доступен при наведении
на имя/значок общего SourceSummary. Обновить и Закрыть остаются внизу окна,
длинный список прокручивается отдельно. Права удаления этим редизайном не меняются.

Закрытие окна прекращает наблюдение за его внешним редактором. Сам редактор
продолжает работать; неподтверждённая копия остаётся защищённой. Список не
возобновляет наблюдение и не доводит сеанс после закрытия окна. Это уточнение
[границ реализации](implementation-scope.md) отменяет прежнее требование
application-owned продолжения внешнего сеанса.

Вход — существующая команда временных файлов. Закрытие списка не завершает
сеансы и операции. «Обновить» перечитывает фактический реестр; не объявляет
внешнюю программу завершённой и не снимает защиту по возрасту файла.

| Состояние | Доступное действие |
| --- | --- |
| Открыт во внешней программе | Сведения о сеансе; удаление недоступно |
| Наблюдение прекращено | Копия сохранена; нет возобновления проверки/обновления и разрешения очистки |
| Завершение неизвестно | Сведения, сохранение отдельной копии, ручная проверка; очистка защищена |
| Есть несохранённые в архив изменения | Сведения/экспорт/обновление; удаление только после доказанного завершения и отдельного решения |
| Архив обновляется | Сведения об операции; удалить вход нельзя |
| Завершённая копия, защита снята | Удалить копию |
| Ошибка удаления | Причина рядом, запись остаётся; можно повторить |
| Пусто | Явное пустое состояние, без фиктивного выбора/действий |

«Удалить изменения…» объясняет, что изменения не попали в архив и удаление
необратимо. Начальный фокус — «Отмена»; Escape сохраняет запись. Это разрешение
касается выбранной копии, не всех последующих изменённых файлов. Без доказанного
завершения даже такая кнопка не обходит внешнюю защиту. Экспорт копии не является
автоматическим разрешением её удалить.

Действующий [реестр владельцев](../../../src/platform/temp/qtownedtempregistry.h)
регистрирует созданные приложением объекты, держит active leases и признак
неподтверждённого внешнего использования. Cleanup должен повторно получить
право удаления и сверить сохранённую OS identity. Похожее имя/путь/возраст
не являются доказательством владения. Смена объекта, symlink или повторное
занятие пути не должны направить удаление на чужие данные.

Текущие [правила доступности](../../../src/dialogs/browse/qttempbrowsepresentation.cpp)
и [удаление](../../../src/dialogs/browse/BrowseDialog2.cpp) прочитаны: активные и
externallyProtected записи недоступны для удаления, ClaimForDeletion перепроверяет
право. Сохраняем эти границы; состояние изменённой копии и её связь с внешним
сеансом добавляются существующему владельцу, а не выводятся из имени каталога.

Полные пути доступны в подсказках и сведениях соответствующего сеанса, но не
становятся редактируемым полем для выбора любого каталога.
Длинный список прокручивается внутри окна, нижние «Обновить» и «Закрыть» видны.

Проверка реализации: только свои объекты, active/protected/dirty/clean, changed
identity между показом и удалением, partial deletion/error без ложного исчезновения,
Cancel/Discard, обновление списка после операций, несколько окон и повторный
запуск. HTML работает с демонстрационными записями и не удаляет файлы на диске.
