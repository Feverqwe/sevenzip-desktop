# Файловые действия и проверка архива

Автономное уточнение 5 ноября 2026 в рамках разрешённой проработки. HTML
показывает переходы и типизированные намерения; он не запускает внешние
программы, не проверяет архивы и не изменяет файловую систему.

## Один контекст команды

Меню, контекстное меню, панель действий и клавиатура используют одну проекцию
доступности. Она учитывает provider, его capabilities, выделение, текущий
элемент, загрузку и выполняемую операцию. Проверка повторяется при исполнении:
открытое меню не сохраняет право на действие после смены состояния источника.
Вызов захватывает окно, панель, источник и идентичности объектов. Дальнейшие
изменения выбора не подменяют вход операции.

| Контекст | Доступное поведение |
| --- | --- |
| Пустая папка | Нет действий над выбранными файлами; создание возможно при праве записи |
| Загрузка / ошибка доступа | Не запускать действие по старому содержимому |
| Корневой список томов | Можно открыть том; сам объект тома не копируется и не удаляется как обычный файл |
| Ограниченное чтение | Чтение и копирование наружу; перемещение, удаление, переименование и создание в источнике выключены |
| Обычная папка | Действия по выделению и поддержке источника |
| Открытый архив | Отдельно учитывать чтение записей и возможность изменения контейнера |

Разрешение в HTML — лишь демонстрационная модель этих состояний. В Qt сохранять
существующие native command projection и transport capabilities. Не определять
права по переведённым именам, суффиксам пути или подписи типа файла. Реальная
операция всё равно проверяет источник и сообщает отказ, если права изменились.

## Открыть, просмотреть, редактировать

Обычное открытие папки или архива продолжает навигацию. Внешнее открытие,
просмотр и редактирование — разные намерения. Просмотр использует viewer,
редактирование — editor, обычное внешнее открытие — системную ассоциацию.
Работа с архивной записью проходит через существующее извлечение и
[владельца временной копии](external-file.md). Read-only источник не запрещает
править экспортированную копию; он запрещает сохранять изменения обратно.
Просмотр сам по себе не является гарантией неизменности временного файла.

Действие относится к текущему файловому элементу, а не к первой строке
многозначного выделения. Для папки «Просмотр» и «Редактировать» выключены.
Это явное уточнение нового меню: старый native View также мог рассчитывать
размер папки; не прятать расчёт размера под командой просмотра файла.
Не подменять эти действия открытием демонстрационного текстового отчёта.

В HTML внешний запуск обычного файла публикует review intent с контекстом и
open/view/edit. Для архивной записи открываются сведения о временной копии,
чтобы можно было проверить продолжение сценария без настоящего редактора.

## Проверка архива

В файловой папке проверяются выбранные файлы, переданные официальному движку.
Не ограничивать распознавание только известными расширениями и не подставлять
пример архива вместо выбранного файла. Нераспознанный формат — результат
операции с конкретным источником. Папки и namespace томов не являются такой
пакетной проверкой.

Внутри архива выделение задаёт область проверки записей. При отсутствии
выделения проверяется весь открытый архив. В окне операции явно указана эта
область, а раскрытие «Что проверяется» показывает входные объекты. Существующие
native индексы, вложенность и ограничения конкретного reader сохраняются;
нельзя молча заменить проверку выбранных записей проверкой другого файла.

Используется общее самостоятельное [окно операции](operation-progress.md).
У проверки нет папки назначения и конфликтов перезаписи. Возможны пароль,
лимит памяти, ошибка чтения, неподдержанный метод и контрольная ошибка.
Наличие записей или окончание progress не доказывает целостность: результат
берётся от движка. Отмена и пропуски оставляют явный неполный результат,
без сообщения об успешно проверенных непрочитанных данных. При отмене не
показывать предупреждение об уже записанных файлах: проверка не извлекает их
в выбранную пользователем папку.

## Реализация и evidence

Прочитаны CPanel::EditItem, открытие конкретного файла, TestArchives,
QtFileManagerCommandWorkflows, Qt command availability и MainWindow::testArchive
на базе e16690f7. Используются существующие владельцы viewer/editor, archive
callback и ArchiveBackend; новых алгоритмов и внешнего заимствования нет.
Проверка native RAR с неподходящими индексами имеет существующий отказ;
дизайн не означает, что отсутствующая поддержка уже реализована.

Браузером проверены пустое место, загрузка, ошибка, обычный и read-only архив;
раздельные view/edit/open intents, запрет Move/Delete в read-only, область
выбранных записей и всего архива, остановка с неполным итогом. Это evidence
HTML-переходов, а не runtime проверки движка или внешнего процесса.
При Qt реализации отдельно проверить capability drift, смену активной панели,
две панели/окна, пакет нескольких файлов, неизвестный формат, пароль,
ошибку контрольной суммы, неподдержанный метод, отказ запуска и отмену.
