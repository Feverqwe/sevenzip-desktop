# Удаление

Статус: проработано автономно по поручению пользователя 5 ноября 2026, v39.
[Макет](../index.html?review=delete-v39#delete). Нативное приложение не изменено;
демонстрационная операция не удаляет реальные или тестовые файлы.

## Состав и действия

Используются общие DialogSurface, SourceSummary, InlineMessage и ActionBar из
[компонентной системы](design-system.md). Для одного объекта сразу показываем
его имя. Для нескольких показываем число объектов и весь список имён с
прокруткой при необходимости. Исходное место доступно в подсказке.
Последствия видны над списком.

Заголовок «Переместить в Корзину?» и кнопка «В Корзину» используются для
файлов и папок. Если источник только для чтения или не поддерживает Корзину,
действие недоступно. Записи внутри архивов нельзя переместить в Корзину,
поэтому команда удаления внутри архива недоступна.

Для папок видно, что перемещается и их содержимое. Нижние действия доступны
при прокрутке длинного списка. Начальный фокус на «Отмена». Escape возвращает
в список с исходным выделением. В macOS команда вызывается по ⌘Backspace вне
режима редактирования текста.

## Операция и результат

Подтверждение захватывает источник и выбранные объекты. Ход работы использует
общее окно операции. После частичного отказа показываем ошибки и перечитываем
источник. Если перемещение в Корзину не удалось, показываем ошибку и сохраняем
файл на исходном месте. Для реализации используется существующая
[служба Корзины](../../../src/platform/trash/qttrashservice.h).
