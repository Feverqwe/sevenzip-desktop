# Настройки

Актуализация макета v64. Актуальный состав настроек задан планом сокращений. Сохраняются оформление, язык, ассоциации, лимит памяти и рабочая папка.
Описания прежних поверхностей ниже сохранены для справки. См. [план интерфейса](implementation-scope.md).

Уточнение памяти: постоянный лимит связан с [формой запроса памяти](memory-request.md),
но разовый Allow и Repeat текущей операции не меняют настройки. Единица явного
лимита — ГиБ (2^30 байт); неизвестная RAM не показывается как нулевой объём.

Статус: проработано автономно по поручению пользователя 5 ноября 2026, v37.
[Макет](../index.html?review=settings-v37#settings-view).

Одно окно настроек приложения с постоянной навигацией по разделам. Окно
использует доступное место; в компактном размере навигация переносится наверх,
прокручивается содержимое раздела, действия остаются доступны. Встроенной
справки нет. Смена раздела сохраняет черновик.

| Раздел | Основное содержимое |
| --- | --- |
| Основные | Оформление и язык |
| Открытие файлов | Поиск форматов, выбор приложения Sevenzip и фактическое состояние ассоциаций |
| Память | Необязательный лимит распаковки; реальный доступный диапазон задаёт существующий владелец лимита |
| Временные файлы | Системная, текущая или выбранная рабочая папка |
| Список файлов | Отображение и дополнительные режимы управления; исходный режим остаётся согласованным Finder/Explorer |

Сохраняем «Применить», «Отмена» и «Сохранить». Применить фиксирует текущие
изменения и оставляет окно открытым. Отмена отбрасывает оставшийся черновик,
сохраняя уже применённое. Сохранить применяет изменения и закрывает окно только
при завершении применения без нерешённых ошибок. Enter не должен срабатывать
во время редактирования многострочного поля или выбора списка; Escape отменяет
черновик. Повторное открытие показывает сохранённое состояние.

Нет обещания атомарного отката системных ассоциаций. Текущий native apply может
сохранить другие страницы, даже если система отказала в изменении ассоциации.
Интерфейс сообщает, что применено, сохраняет неприменённый выбор и остаётся
открытым. Внешнее изменение ассоциации требует актуального состояния, без
молчаливой перезаписи. В макете есть соответствующие состояния раздела
«Открытие файлов». Фактический системный результат в HTML не эмулируется.

Выбор файла по умолчанию зависит от возможностей ОС. Не обещаем, что checkbox
сам по себе меняет любую системную ассоциацию. При необходимости открывается
системная поверхность, а итог перечитывается. Права администратора и системные
ограничения не заменяем собственным диалогом ввода пароля.

Во временных папках macOS не показываем Windows-only настройку определения
съёмных дисков. Поля и значения, скрытые на платформе или исключённые из
повседневной формы, не сбрасываются при сохранении остальных настроек.
Рабочая папка проверяется существующей native операцией; изменение предпочтения
не переносит и не удаляет старые временные данные.

Внешние файлы открываются через системную ассоциацию. Полная цепочка описана в [файле во внешней программе](external-file.md),
а сохранение и очистка копий — во [временных файлах](temporary-files.md).

Основания: просмотрены QtFmOptionsDialog::apply/accept/reject и владельцы
FoldersPage/SettingsPage. Сохраняются их настройки и native границы;
новые алгоритмы чтения/записи конфигурации не добавлены. В HTML исправлены
черновики, применение и отмена, общий сохранённый пример между окнами,
валидация положительного целого лимита и компактная прокрутка всех разделов.
Полноценное единственное Qt Settings-окно, применение реальных ассоциаций ещё требуют реализации и проверки на своей ОС.

Проверки будущей реализации: отмена между несколькими страницами; Apply,
дальнейшая правка и Cancel; Save с ошибкой; частичный системный отказ;
внешнее изменение; сохранение скрытых предпочтений; смена языка/оформления;
валидный/невалидный лимит; компактная
геометрия и фокус. Проверять результат, не внутренний порядок сохранения страниц.
