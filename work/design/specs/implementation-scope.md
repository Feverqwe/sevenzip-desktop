# План реализации нового интерфейса Sevenzip

Документ объединяет согласованные решения и последующие уточнения.
Он имеет приоритет над прежними рекомендациями
аудита необходимости, ранними спецификациями
и существующими демонстрационными экранами.

Задача для агента реализации — привести Qt-приложение к этому контракту.
[Макет](../index.html), [сценарии](../scenarios.md), [главное окно](../implementation-main-window.md)
и [компоненты](design-system.md) уточняют компоновку и поведение. Снимки текущего
приложения и ранние спецификации служат справкой.

«Удалить» означает убрать функцию из приложения, включая меню, контекстное
меню, кнопки, сочетания клавиш, настройки и альтернативные маршруты запуска.
Удалить реализацию и регистрацию, используемые только этой функцией, после
проверки прямых потребителей. Отдельно отмечены случаи, когда удаляется лишь
старое окно, а нужное действие переносится. Общие компоненты движка,
CLI и поддержка данных сохраняются по потребителям.

## Окна и перенос действий

| Поверхность | Решение |
| --- | --- |
| Вкладки и боковая панель | Удалить из Qt вместе с командами вкладок, переносом между окнами, восстановлением вкладок и отдельной панелью мест. Сохранить независимые окна и дополнительный режим двух панелей |
| «Лицензии и уведомления» | Убрать окно и переход к нему из «О программе». Лицензии и уведомления входят в поставку |
| «Недавние места» | Заменить окно коротким списком у адресной строки. Убрать отдельные поиск и редактор истории |
| «Временные файлы» | Убрать менеджер. Безопасные копии очищаются автоматически по правилам владения. Изменённую копию можно сохранить при работе с файлом |
| «Запрос памяти» | Убрать диалог. Если лимит остановил обработку, в результате показать требуемый и разрешённый объём. Повтор возможен после явной смены лимита в настройках |
| «Файл во внешней программе» | Открывать файл сразу. При обнаружении изменений показать доступные действия для обновления архива или сохранения отдельной копии |
| Результат расчёта контрольных сумм | Для одного файла показать в свойствах, для нескольких — в общем отчёте операции |
| «Создать файл контрольных сумм», «Проверить файлы по списку» и результат такой проверки | Удалить обе функции из GUI, включая специальное открытие файла сумм. Сохранить расчёт суммы выбранным алгоритмом и отдельную команду проверки архива |
| «Создать папку» | Ввод имени прямо в списке. Ошибка имени показывается рядом с полем |

Сокращения согласованы пользователем. Для временных копий сохраняется защита открытых,
изменённых и неподтверждённых данных. Для памяти нужно сохранить действующий
лимит и различать остановку по лимиту и фактический отказ выделения памяти.

| Команды контроля версий | Обычные файловые и архивные операции |

| Пакетную распаковку нескольких отдельных архивов | Распаковку одного архива целиком или нескольких выбранных объектов внутри одного открытого архива. В файловой панели при выборе нескольких архивов команда недоступна |

| Команду расчёта сразу всех алгоритмов контрольных сумм | Выбор конкретного алгоритма и показ значения в свойствах или результате операции |
| «Копировать сведения», «Сайт 7-Zip», отдельные состояния ошибки открытия ссылки и недоступного модуля в «О Sevenzip» | Версии, атрибуцию, сведения о сборке и сайт проекта |
| Режим распаковки «Переименовать существующий файл» | «Заменить», «Пропустить», «Сохранить оба» и отмену; старый файл при «Сохранить оба» остаётся под своим именем |

### Что убираем только из простой формы

Это сокращение поверхности UI, а не удаление соответствующего режима движка.

| Возможность | Решение |
| --- | --- |
| Техническое открытие `*` и `#` | Убрать из обычного меню; понятное «Открыть как архив» сохранить |
| Синхронизация архива с папкой | Убрать из простого интерфейса; native-режим синхронизации не удалять автоматически |
| Абсолютные пути при распаковке | Убрать выбор из пользовательской формы; извлечение в выбранное место и проверки путей сохраняются |

## Что объединяем

| Прежняя отдельная поверхность | Куда переносим |
| --- | --- |
| Отдельное окно сообщений и длинного отчёта, раскрытие «Подробный отчёт» и кнопка «Копировать отчёт» | Сообщения и результаты видны сразу в прокручиваемой области операции. Пустой блок отсутствует |

Из предложений об объединении архивных форм согласован перенос отчёта.
Самостоятельные архивные формы, включая «Метаданные и время», остаются в каталоге.

В отчёте сохраняются конкретная причина, затронутые файлы, неполные результаты
и рассчитанные хеши. Итог операции выводится обычным текстом без рамки.

Отдельная ошибка размера части исчезает вместе со Split/Combine. Не переносить
её в новую форму и не разрабатывать удаляемые окна ради завершения каталога.

## Что оставляем

### Основные сценарии

| Область | Сохраняем |
| --- | --- |
| Файловый менеджер | Папки и файлы, адрес и навигацию, строку `..` и отдельные окна |
| Представление | Таблицу, крупные значки, сортировку и системные значки файлов; две панели как дополнительный режим |
| Файловые операции | Создание папки, переименование, Copy/Paste, «Копировать в…», перенос файлов и перемещение в Корзину по поддержке источника |
| Архивы | Открытие, просмотр, вложенные контейнеры по поддержке, создание, обновление, распаковку одного архива целиком или выбранных объектов внутри него и проверку архива |
| Открытие файлов | Системное приложение, существующую подготовку временной копии и поддержанное возвращение внешних изменений в архив |
| Операции | Ход, остановку, реальные возможности паузы, конфликты, ошибки, пропуски, отмену и достоверный частичный результат |
| Свойства и суммы | Все доступные сведения и список объектов видны сразу. Сумма одного файла показывается в свойствах, суммы нескольких файлов — в отчёте операции |
| Системная интеграция | Ассоциации, интеграцию Sevenzip в меню ОС и доступ к системным действиям по возможностям платформы |
| Сведения | «О программе» |

Строка `..`, таблица, крупные значки и дополнительный режим двух панелей сохраняются.
Скрытие команды редактирования ссылок или просмотра потоков не разрешает терять
эти данные при операции, которая их поддерживает.

### Обязательные SMB и устройства

| Сценарий | Полный сохраняемый путь |
| --- | --- |
| SMB-подключение архива/образа как папки в ОС | Подготовка, отмена, пароль при необходимости, кеш по необходимости, разрешение извлечения, отдельное решение о непроверенных данных, открытие в ОС, путь и диагностика |
| Управление подключениями | Несколько сессий, обычное отключение, сохранение занятого подключения, отдельное принудительное отключение и существующий вопрос при закрытии владельца |
| Устройства | Выбор устройства/раздела, обновление списка, системный доступ, ошибки и отключение источника, прямое чтение без изменения носителя и копирование наружу |
| Ограниченное чтение | Конкретная причина и выбор продолжить, видимая отметка режима, честный результат доступных/непрочитанных данных |

Обязателен локальный SMB-сценарий подключения контейнера к Finder/Проводнику
или другому файловому менеджеру ОС. Новый клиент для NAS/чужого SMB-сервера
не добавляется. Работа с устройствами не означает добавления форматирования,
ремонта, записи образов или воспроизведения журнала.

полезность остальных оставшихся сценариев; этот план не объявляет измеренную
частоту их использования.

### Поведение окон, которое переносим в Qt

- В прогрессе конфликт и запрос пароля сразу открывают существующий диалог
  поверх окна операции. Прогресс остаётся виден под ним, его действия временно
  недоступны. Убрать промежуточные экраны ожидания и кнопки перехода к запросу.
  Сворачивание доступно через заголовок окна. В конфликте «Отмена» слева, три
  решения справа в той же строке. Флажок применения к остальным конфликтам
  действует только на текущую операцию.
- «О Sevenzip» и «Свойства объектов» закрываются через заголовок или Esc.
  Дублирующие нижние кнопки «Закрыть» удалить. В свойствах «Копировать
  сведения» остаётся. В подтверждении удаления список файлов виден сразу.
- Для обычного выбора файлов и папок используется системная панель. Существующий
  запасной браузер сохраняется для поддержанных исключений, включая длинные пути.
  У него изменяемый размер, список занимает свободную высоту и прокручивается
  внутри. Поле пути и действия остаются видимыми. Короткая форма в HTML
  обозначает системный вызов.
- Стартовый размер определяется типом окна. Короткие диалоги подстраиваются
  по высоте под содержимое. У изменяемых окон содержимое следует за рамкой,
  а кнопки остаются доступны. Числа из HTML служат ориентиром. Qt учитывает
  доступное место, метрики платформы, шрифт и переводы.
- Формы используют общую адаптивную сетку подписей и полей. В узком окне
  поле переходит под подпись. Зазор до раскрытого содержимого задаёт общий
  компонент раскрытия, в том числе для секций с флажком. Сетка управляет
  расстоянием между полями.
- В «Подключённых папках» начальная высота соответствует содержимому, окно
  растягивается. Пустое состояние центрируется. «Отключить принудительно…» и
  «Убрать из списка» входят в строку действий соответствующего подключения.

## Порядок выполнения

1. Сверить команды, вызовы, ресурсы и прямых потребителей затронутых функций.
   Для переносимых модулей выполнить требуемое source comparison. Отделить
   самостоятельные удаляемые функции от общих компонентов оставшихся операций.
2. Начать с главного окна и его команд. В каждом затронутом сценарии сверять
   приложение с макетом и этим планом. Старые снимки native служат сравнением.
3. Выполнить удаления из таблиц выше. Проверить все точки входа, в том числе
   настройки из прежних версий. Удалить код и регистрацию в сборке, нужные
   только удаляемым функциям.
4. Подключить объединённые поверхности и оставшиеся действия к существующим
   владельцам операций. Обновить доступность и клавиатурные входы вместе с меню.
   Ранее сохранённые предпочтения не должны возвращать удалённый режим.
5. Выполнить focused проверки затронутых сценариев и их прямых потребителей.
   Исправить найденные несоответствия и обновить документы с изменившимися
   пользовательскими контрактами.

Это последовательность работ, а не требование отдельного коммита на каждый
пункт. Коммиты создаются только по прямому запросу пользователя.

## Критерии завершения

- Удалённые функции не вызываются из меню, контекста, панели, клавиш и старых
  предпочтений. Не оставлены доступные пустые формы или команды без действия.
- Сохраняемые файловые, архивные, SMB- и device-сценарии работают с прежними
  проверками путей, прав, паролей и read-only границ.
- Обычное открытие использует системную ассоциацию. Вопрос о неизвестном типе
  остаётся без отключающей настройки. Настройки приложений и аргументов
  командной строки в GUI отсутствуют.
- Перемещение в Корзину проверено при успехе и отказе, включая отсутствие
  безвозвратного запасного маршрута. В архиве команда удаления недоступна.
  При выборе нескольких архивов пакетная распаковка недоступна.
- Конфликт различает замену, пропуск и сохранение обоих. Поддержанные ссылки,
  потоки и метаданные не теряются из-за удаления их отдельных редакторов.
- Проверены положительный результат, отказ и отмена затронутой операции;
  частичный результат не объявляется полным успехом.
- Проверяется наблюдаемое поведение, а не наличие/отсутствие строк в исходниках.
  Существующие тесты удалённых функций корректируются по новому контракту;
  полезное покрытие общих компонентов сохраняется.
- Для layout-изменений проверены соответствующие normal/compact состояния
  и widget JSON. Общая переносимая логика проверяется сначала на Linux;
  системные границы SMB, устройств и меню — на затронутой ОС.
- Макет, реализация и runtime-проверки получают собственный фактический статус.
  Проверка этого плана или HTML не считается приёмкой Qt-приложения.

## Сохраняемые границы поведения

- Обработка паролей и шифрования остаётся прежней. Перенос контекста шифрования не добавляется как новая функция.
- Существующие native-проверки записи сохраняются. Не добавляются привязка внешней правки к сохранённой версии архива, новые запреты при смене архива и дополнительная защита от подмены цели записи.
- При восстановлении открывается директория. Ранее открытый архив и его вложенная цепочка не восстанавливаются.
- После закрытия файлового контекста редактор продолжает работать, а неподтверждённая временная копия остаётся на диске.

Существующие проверки временных файлов, прав доступа, путей и native-операций
этими границами не отменяются. Recovery scope не расширяется автоматически
на все форматы и файловые системы.
